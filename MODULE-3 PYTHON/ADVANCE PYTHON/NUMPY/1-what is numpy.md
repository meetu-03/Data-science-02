# What is NumPy?

1. NumPy is used for numerical computing in Python. It is a library that provides support for large multi-dimensional arrays and matrices, along with a collection of mathematical functions to operate on them.

2. NumPy is a third-party library in Python. It is not part of the standard library, so you need to install it separately using `pip install numpy`.

3. NumPy is used for working with arrays and matrices, which are more efficient than Python's built-in lists for numerical computations.

4. It provides a wide range of functionality for mathematical operations, linear algebra, statistical analysis, and more.

5. NumPy is used for linear algebra in Python.
