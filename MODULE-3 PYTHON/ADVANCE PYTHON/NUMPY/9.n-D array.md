n-D array (tensor)

1. a tensor is multi dimensional array that can be represented as N dimensional array also call tensor in python 

2. it is a generalized scaler vector matrix to higher dimension of array to stored data [[[1,2],[3,4],[[5,6],[6,7]]]]

**example**

import numpy as np
arr=np.array([[[1,2],[2,3],[[4,5],[5,6]]]])
print(arr)
